# 下载简历的 PDF 版式优化

## 方向

沿用网站的墨绿视觉识别，采用白底与浅绿成果面板，兼顾电子投递和打印。相比深色满版，它能提供更稳定的纸面阅读体验；相比单纯更换字体，固定分页与信息层级能解决原文件的跨页断裂及尾页空白问题。

## 内容与分页

- 第 1 页：个人信息、技术专长、赛力斯企业培训与学习管理平台。
- 第 2 页：AI-CloudOS、NebulaAI、ATC。
- 第 3 页：四段工作经历、教育经历。

保留来源简历的事实、职责与技术栈，对重复标题、数学公式转义与标点做排版整理。NebulaAI 复杂度说明沿用网站对增量更新场景的限定。原文 `2017.00` 无有效月份，结束时间显示为 `2017`，不补造月份。

## 实现与验证

由 ReportLab 生成 A4 PDF，嵌入中文和展示字体，保留文本提取能力和联系方式链接。内容与模板分别保存在 JSON 和 Python 脚本中，以 `uv` 管理脚本依赖。排版预先测量内容高度，超过页面可用空间时终止生成，避免静默裁切。

交付前检查三页渲染、完整文字、字体嵌入、链接、页码和页面边界。更新网站下载文件并增加链接版本标记，通过 GitHub Pages 发布。
