# 作品集视觉特效实现计划

**目标：** 在现有荧光绿科技风格中增加清晰可见的空间变化、滚动节奏与交互反馈。

**架构：** 首屏圆环保留 Canvas 渲染，在原组件中管理滚动进度与轨道光效；章节通过独立组合函数管理一次性入场和可见状态；卡片与联系区使用 CSS 装饰层。所有新增动画响应现有暂停状态及系统减少动态效果设置。

**技术栈：** Vue 3、TypeScript、CSS、IntersectionObserver、requestAnimationFrame，沿用 pnpm 工作区。

## 实现步骤

1. `OrbitVisual.vue`：增加滚动旋转与收缩、轨道粒子；清理监听器，离屏和暂停时停止帧循环。
2. `useScrollReveal.ts` 与 `App.vue`：观察内容块并按组错峰显示；以独立 translate 属性避免覆盖已有卡片倾斜；暂停、键盘聚焦和系统减少动态效果时确保内容可见。
3. `ProjectsSection.vue` 与 `style.css`：加入卡片边缘流光和预览扫描，悬浮与键盘聚焦均有反馈；装饰层不拦截点击。
4. `ContactSection.vue`：增加背景大字、柔和极光与轨道线；复制成功提供明显反馈，兼顾窄屏。
5. 运行 `pnpm lint`、`pnpm typecheck`、`pnpm build`；浏览器验证桌面、移动端、项目弹窗和筛选、暂停动效及横向溢出。

## 验收条件

- 滚动时首屏与章节有明显且连贯的变化。
- 项目筛选、详情弹窗、导航和邮箱复制保持可用。
- 暂停动效后新增装饰停止，未进入的内容仍可阅读。
- 窄屏无横向溢出，装饰不遮挡正文或点击区域。
