# 新版简历项目内容更新

内容依据：用户提供的 2026-10-13 版本《吴伟东｜前端工程师》简历。

## 展示方向

保留现有深色、荧光绿和动态概念预览。新增「赛力斯企业培训与学习管理平台」并置于首位，以四个项目展示企业业务交付、AI 工程化、流式渲染和可视化编排能力。桌面采用两列卡片，移动端单列。

## 内容结构

- 卡片：项目定位、简短业务描述、负责方向、核心技术和代表成果。
- 详情：业务场景、我的职责、关键技术方案、交付成果、分组技术栈。
- 分类：全部、企业业务、AI 应用、可视化；数量从共享项目数据派生。
- 数据：继续维护在 workspace 内容包中，详情组件通过明确的 Project 类型接收内容。
